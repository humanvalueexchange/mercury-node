# Contributing to Mercury Node

Mercury Node is currently in **private development** ahead of our Q3 2026 public launch.

If you're reading this before the public launch: welcome. You're early.

---

## When We Go Public

At v1.0 launch, Mercury Node will be fully open for contributions. We'll add:

- Issue templates
- Pull request guidelines
- Code of conduct
- Development environment setup guide

---

## In the Meantime

- **Star this repo** to be notified at launch
- **Issues:** Open an issue if you've been given access and find a bug
- **Contact:** cto@hvecorp.com for early contributor inquiries

---

## Core Principles for Contributors (preview)

1. **Sovereignty first** — every change must preserve the user's full control over their funds
2. **Native binaries only** — no Docker, no Snap, no containers
3. **Agent is a guest** — the intelligence layer must never be a dependency of the Bitcoin stack
4. **Honest UX** — never hide tradeoffs from the user
